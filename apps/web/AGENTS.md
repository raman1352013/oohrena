# apps/web

Read the root [`AGENTS.md`](../../AGENTS.md); it holds every rule for this app (§5 step 6, §5a, §6).

- `src/lib/api.ts` is the only fetch wrapper; `src/lib/<domain>-api.ts` holds the TanStack Query hooks.
- `src/components/app/kit.tsx` is the only set of UI primitives.
- `src/routeTree.gen.ts` is generated by `npm run build` / `npm run dev`; never edit it.
- Run `npm run typecheck`, `npm test`, `npm run lint` and `npm run build` in this folder before committing.
